Full-stack web app · PWA + Android

Gym Tracking

A strength-training log built for real gym conditions: one hand, a phone, and sometimes no signal. Log every set with weight, reps and RPE; the app works out volume, estimated 1RM, personal records and trends, and suggests when to add weight. Designed and built with AI-assisted development (Claude).

  • Security lives in the database: Supabase Row Level Security, with pgTAP tests proving one user can't see another's data.
  • Offline-first sessions: client-generated IDs and a durable IndexedDB queue that syncs on reconnect.
  • Layered architecture: all analytics in a pure domain layer, testable without a browser.
  • ~100 unit and integration tests (Vitest), 10 end-to-end (Playwright), CI on GitHub Actions.
  • Installable PWA and Android APK, deployed on Vercel. English/Spanish, light/dark.

Data analysis · Dataset + dashboard

World Cup 2026 Squads

Who actually gets called up to a World Cup? I scraped all 1,248 players on the 2026 squad lists from Wikipedia and took them through the full analytics cycle: extract, clean, query and visualize.

  • Three-notebook pipeline: scraping (Requests, BeautifulSoup), cleaning (Pandas, regex), and SQL analysis on a SQLite database.
  • Raw and cleaned versions published on Kaggle so anyone can reuse them.
  • Findings: goalkeepers are the oldest group (29.8 on average); Manchester City sends the most players (19).
